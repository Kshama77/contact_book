# ContactBook

A simple Java console application for storing and managing contacts.

## Features

- Add contacts
- View all contacts
- Update contacts
- Delete contacts
- Uses Java objects
- Uses `ArrayList`
- Uses basic CRUD operations
- Uses loops, methods, conditionals, and `Scanner`

## Concepts Practiced

- Classes and objects
- Constructors
- Encapsulation
- Getters and setters
- Arrays/collections with `ArrayList`
- CRUD operations
- `for` loops
- `if` statements
- `switch`
- Methods
- User input with `Scanner`
- Basic exception handling

## How to Run

Make sure Java is installed.

From the project folder:

```bash
javac src/*.java
java -cp src ContactBook
```
